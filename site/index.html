Provenance on every claim

A claim carries its author's key, its record time, the tool behind it, its sources, a confidence and a note. Nothing is edited: a change is a new claim.

Design principles of the format

From docs/DESIGN.md, the contract the code is built against.

  • Three primitives

    Blob, entity, claim. Everything else is a claim.

  • Assertions, not truth

    Contradictory claims coexist; reads resolve them.

  • Two times

    Record time and world time, which may be fuzzy.

  • Kernel frozen, vocabulary open

    Only the knowa: namespace is reserved.

lisbon
$knowa --json schema | jq -r .overview Knowa is a local-first knowledge base of signed, append-only claims. Humans and agents write claims (subject, predicate, typed value) under their own actor keys; everything else (entities, status, search, graph) is derived at read time. Five primitives: write, blob.put, blob.get, query, feed. The claim format and the query/result documents only change additively: ignore unknown result fields.

Sharing a space in three steps

Spaces are private by default. You choose what leaves, at shared or public level.

  1. Mark the notes and files to share

    Set an entity to shared or public. Everything else stays private.

  2. Export a bundle of signed claims

    A shared bundle leaves out the notes and files that are still private.

  3. Import and verify the claims

    Import checks every signature, blob hash and chain, then registers the space read-only.

Build the CLI from source

There is no public release yet. From a checkout of the repository, Cargo builds and installs the CLI.

knowa
$cargo install --path crates/knowa-cli

Is there a hosted Knowa service?

No. It runs on your machine, in ~/.knowa or KNOWA_HOME.

Which language models can write claims?

Any program can be a worker; no LLM provider is linked in.

Which parts of the CLI are experimental?

Object storage and the local web UI, knowa serve.

Can an agent sign claims as me?

No. Each agent signs with its own key, never a human's.

Where is the format specified?

In docs/DESIGN.md, which the code must follow.

Run Knowa on your own machine

One Cargo command from a checkout of the repository. Spaces stay private until you export them.
